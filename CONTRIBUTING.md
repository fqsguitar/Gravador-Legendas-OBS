# Contributing / Como contribuir

[English](#english) · [Português (Brasil)](#português-brasil)

## English

Thanks for helping improve this project!

1. Open an issue describing the bug or proposed feature before major changes.
2. Fork the repository and create a branch from `main`.
3. Keep changes focused and submit a pull request explaining how you tested them.
4. Do not commit meeting recordings, transcripts, credentials, logs, compiled executables, or private configuration.
5. Test OBS mode on Windows with OBS running, WebSocket enabled, and a short recording; verify matching SRT/TXT files and that the tray remains green after completion.
6. If you change the standalone audio mode, clearly label it experimental until verified.

For bug reports include Windows version, OBS version, app version, selected Whisper model, reproduction steps, and **redacted** error logs. Never share WebSocket passwords or meeting content.

## Português (Brasil)

Obrigado por contribuir!

1. Abra uma issue descrevendo o erro ou a melhoria antes de alterações grandes.
2. Faça um fork, crie uma branch a partir da `main` e envie um pull request.
3. Explique o que mudou e como testou.
4. Não publique gravações de reuniões, transcrições, credenciais, logs, executáveis ou configurações privadas.
5. Teste o modo OBS no Windows: OBS aberto, WebSocket habilitado, gravação curta, SRT/TXT com o mesmo nome do vídeo e bandeja verde ao concluir.
6. Mudanças no modo somente áudio devem continuar marcadas como experimentais até validação.

Ao relatar erros, informe versões do Windows, OBS e aplicativo, modelo Whisper, passos para reproduzir e logs **sem informações sensíveis**.
